# andydndboi

Landing page for Andreas, Dungeon Master for hire. Vite + React + GSAP, static, deploys on Vercel.

- `npm install && npm run dev`: local dev
- `npm run build`: production build into `dist/`
- Copy (EN + NO): `src/i18n.js` · name/email: top of `src/App.jsx` · prices: `src/pricing.js` · days off: `src/AvailabilityCalendar.jsx`
